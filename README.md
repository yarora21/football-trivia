# NFL Trivia — Real-Time Multiplayer Game

A real-time multiplayer NFL trivia game built entirely on AWS serverless. Hosts create rooms with a topic, AI generates fresh questions, and players compete on a live, speed-weighted leaderboard.

## Demo

1. Host creates a room with a topic (e.g. "Super Bowl winners")
2. AI generates unique questions via Amazon Bedrock + ESPN data
3. Players join with a room code and name
4. Questions appear live with a 15-second countdown timer
5. Points are awarded based on correctness and speed
6. Leaderboard updates in real time after each question

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React, Vite, TypeScript |
| Backend | AWS Lambda (Python 3.12) |
| Real-time | API Gateway WebSocket API |
| REST API | API Gateway HTTP API |
| Database | DynamoDB (single-table design) |
| Caching | ElastiCache Serverless (Redis) |
| AI | Amazon Bedrock (Nova Pro) |
| Orchestration | AWS Step Functions |
| Question Timer | SQS (delay queue) |
| Infrastructure | AWS CDK (TypeScript) |
| Networking | VPC with private subnets, VPC endpoints |

## Key Features

- **AI-Generated Questions**: Each room gets unique questions generated by Amazon Bedrock using real ESPN NFL data
- **Speed-Weighted Scoring**: Faster correct answers earn more points (100-1000 per question)
- **Real-Time WebSocket**: All players see questions and leaderboard updates simultaneously
- **Auto-Advance**: Questions automatically advance after 15 seconds, or immediately when all players answer
- **Idempotent Game Loop**: SQS-based timer with idempotency checks prevents duplicate advances


```bash

npm run dev
```

## How It Works

1. **Room Creation**: Host POSTs to `/rooms` → Lambda creates room in DynamoDB → Step Function starts generating questions
2. **Question Generation**: Step Function fetches ESPN data → Bedrock generates questions → validates → persists to DynamoDB
3. **Game Start**: Host sends `host.start` → first question broadcasts to all players via WebSocket
4. **Answering**: Player sends `player.answer` → score Lambda checks answer, calculates speed-weighted points, updates Redis leaderboard
5. **Advancing**: After 15s (or when all answer), SQS triggers advance Lambda → reveals answer → shows leaderboard → broadcasts next question
6. **Game Over**: After final question, broadcasts final leaderboard and marks room as finished
